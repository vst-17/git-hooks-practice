# Git Hooks Practice

Практическая работа №1 

## Тема

Использование Git hooks для автоматизации процессов разработки.

## Описание

В проекте используется Git hook pre-commit.

Перед созданием каждого коммита автоматически выполняются:

1. Проверка форматирования Python-кода с помощью Black.
2. Запуск автоматических тестов с помощью pytest.

Если проверка или тесты завершаются с ошибкой, создание коммита блокируется.
