## 1. Цель работы

Целью практической работы является изучение механизма Git Hooks и его применения для автоматизации процессов разработки программного обеспечения.

В рамках работы реализован локальный Git Hook `pre-commit`, который автоматически выполняет проверки перед созданием каждого коммита.

3. Реализованы автоматические тесты с использованием `pytest`.
4. Настроена проверка форматирования Python-кода с помощью `Black`.
5. Создан Git Hook `pre-commit`.

7. Реализована блокировка commit при обнаружении ошибки.
8. Проверена работа Git Hook на успешном и ошибочном сценариях.
9. Проект размещён в удалённом Git-репозитории GitHub.

## 7. Проверка форматирования с помощью Black

Для автоматической проверки форматирования Python-кода используется инструмент `Black`.

Проверка выполняется командой:

```powershell
black --check .
```

Параметр `--check` позволяет проверить форматирование файлов без их автоматического изменения.

Если форматирование соответствует требованиям Black, проверка завершается успешно.


## 8. Создание Git Hook pre-commit

Для автоматизации проверки перед созданием commit был создан Git Hook:

```text
.git/hooks/pre-commit
```

Git Hook `pre-commit` запускается автоматически непосредственно перед созданием commit.

Основная задача Hook — выполнить проверки и разрешить создание commit только в том случае, если все проверки завершились успешно.


## 9. Содержимое Git Hook

Используемый `pre-commit` содержит следующий код:

```bash
#!/bin/sh

echo "====================================="
echo "Запуск pre-commit hook"
echo "====================================="

echo "Проверка форматирования Python-кода..."

black --check .

if [ $? -ne 0 ]; then
    echo "Ошибка: форматирование кода не соответствует Black."
    echo "Commit отменен."
    exit 1
fi

echo "Форматирование успешно."

echo "Запуск тестов..."

pytest

if [ $? -ne 0 ]; then
    echo "Ошибка: тесты не пройдены."
    echo "Commit отменен."
    exit 1
fi

echo "Все тесты пройдены."
echo "Pre-commit hook успешно завершен."

exit 0
```

## 10. Алгоритм работы Git Hook

Алгоритм работы реализованного Hook:

```text
                    git commit
                        │
                        ▼
                 Запуск pre-commit
                        │
                        ▼
                Проверка Black
                        │
             ┌──────────┴──────────┐
             │                     │
          Ошибка                Успешно
             │                     │
             ▼                     ▼
      Commit отменён          Запуск pytest
                                   │
                         ┌─────────┴─────────┐
                         │                   │
                      Ошибка              Успешно
                         │                   │
                         ▼                   ▼
                  Commit отменён       Commit создаётся
```

Таким образом, перед созданием commit автоматически выполняются две проверки:

1. проверка форматирования;
2. запуск автоматических тестов.

---

## 11. Проверка успешного commit

Для проверки успешного сценария выполняется:

```powershell
git add .
```

После этого:

```powershell
git commit -m "Добавлен pre-commit hook"
```

При выполнении commit Git автоматически запускает `pre-commit`.

В случае успешного прохождения проверок отображаются сообщения о выполнении Black и pytest.

## 12. Проверка блокировки ошибочного commit

Для проверки корректности работы Git Hook был выполнен отрицательный тест.

В функцию `add()` была специально внесена ошибка.

Вместо корректного варианта:

```python
def add(a, b):
    return a + b
```

временно использовался вариант:

```python
def add(a, b):
    return a - b
```

После этого был выполнен commit:

```powershell
git add calculator.py
git commit -m "Проверка блокировки ошибочного кода"
```

Git Hook автоматически запустил тесты.

Один из тестов завершился с ошибкой, поскольку функция сложения стала выполнять вычитание.

В результате создание commit было заблокировано.
